# Changelog

## 0.1.0 (unreleased)

First release, published with the whitepaper *Seven Layers Between a Model and a Claim*.

- Construct statement schema and check (unit 0).
- Fixture builder: keyed splits with a fixed test set, one label rule per task, cutoffs and arms, content-addressed frozen fixtures (unit 1).
- Channel registry and train-only featurizer with no default branch; repair log (unit 2).
- Resumable grid runner with per-run records, working-tree code state, thread counts, cost against a pinned price table, recorded skips and errors, and coverage (unit 3).
- Noise floors by source with a clustered bootstrap (unit 4).
- Decision rules gated by a null-input test; selection on validation only (unit 5).
- Append-only claims register with dated amendments and a document check (unit 6).
- Provenance on every artifact: stamped on write, checked on read, refused on mismatch.
- Synthetic and TrialBench examples, and a defect gallery of the paper's eight failures.
- A user guide in ASD-STE100 Simplified Technical English; a test checks its wording and runs its example files.
